About BugLens

An intelligent software defect triage and diagnosis system powered by an autonomous, multi-stage Agentic AI architecture.

💡 Why Agentic AI instead of a Basic Chatbot?

Standard conversational chatbots attempt to triage a complex software crash in a single monolithic generation. This frequently causes hallucinated root causes, missed telemetry details, and unfocused advice.

BugLens utilizes an Agentic Pipeline where 6 specialized agents execute in sequence with discrete responsibilities, explicit intermediate representations, and cross-verification.

Bug Understanding Agent

Classification Agent

Assigns category, severity level (Critical-Low), priority (P0-P3), confidence score, and forms initial root cause hypothesis.

3

Tavily Technical Research Agent

Constructs precision queries and queries Tavily API to fetch authoritative external docs and known issue resolutions.

↓
4

Evidence Analysis Agent

Cross-references external technical findings with user symptoms; refines the root cause without false certainty.

↓
5

Recommendation Agent

Formulates ordered debugging steps, verification tests, and long-term architectural prevention measures.

↓
6

Final Report Generator

Consolidates all agent outputs into strict RFC-8259 JSON, records execution traces, and persists report in SQLite.

↓
📊

Developer Triage Dashboard

Interactive web inspection, printable report exporter, JSON download, and searchable persistent history.

⚡ Groq API

Provides ultra-fast LLM inference using llama-3.3-70b-versatile. Configurable through .env with strict JSON response enforcement and automated retry logic.

🌐 Tavily Search API

Specialized AI search engine that pulls live technical documentation and GitHub resolutions. Gracefully falls back if keys are unavailable.

🛠️ Python Flask & SQLite

Lightweight, dependable backend with parameterized SQL queries, thread-safe database connection pooling, and RESTful API endpoints.

🎨 Vanilla HTML5/CSS3/JS

Zero heavy frontend dependencies (no React, Bootstrap, or Tailwind). Ultra-fast load times, semantic HTML, and developer-tool design language.
